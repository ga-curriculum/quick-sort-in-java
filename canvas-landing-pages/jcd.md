## About

The name **quick-sort** stems from the fact that it can sort a list of data elements substantially faster (twice or three times faster) than any other sorting method. Quicksort is one of the most efficient sorting algorithms, especially if the data set is large and the degree of randomization is high. It's also the preferred sorting algorithm when allocating additional memory is costly because it's an in-place sorting algorithm. In this module, lets learn what a quick sort algorithm is and how to implement it using Java code.
